# 🌴 Summer Study Planner 🍉

HTML, CSS, JavaScript만으로 만든 개인 학습 플래너 웹앱입니다.  
하늘색 파스텔 톤과 여름 테마를 사용했으며, 포모도로 타이머, 학습 노트, 코드 메모, 마크다운 메모, 이미지 갤러리 기능을 포함합니다.

## 주요 기능

### 1. 타이머

- 일반 타이머
- 포모도로 타이머
- 집중 시간, 짧은 휴식, 긴 휴식 시간 수정 가능
- 4회 집중 후 긴 휴식 자동 전환
- 시작, 일시정지, 초기화 기능

### 2. 학습 노트 및 메모

- 일반 학습 노트 작성
- 코드 메모 작성
  - HTML, CSS, JavaScript, Python, 기타 언어 선택 가능
  - 코드 작성용 어두운 편집 영역 제공
- 마크다운 메모 작성
  - 입력 영역과 미리보기 영역 분리
  - 제목, 목록, 굵게, 인라인 코드, 코드 블록 일부 지원

### 3. 이미지 첨부 갤러리

- 이미지 여러 장 업로드 가능
- 이미지 카드 미리보기
- 이미지 제목 수정
- 이미지 삭제

### 4. 데이터 저장

- 브라우저 `localStorage` 사용
- 새로고침하거나 브라우저를 닫았다 열어도 저장된 데이터 유지
- 저장 대상
  - 학습 노트
  - 코드 메모
  - 마크다운 메모
  - 이미지 갤러리
  - 오늘의 목표
  - 타이머 설정

## 파일 구성

```text
summer-study-planner/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 실행 방법

1. 폴더 안의 `index.html` 파일을 더블 클릭합니다.
2. 웹 브라우저에서 학습 플래너가 열립니다.
3. 별도 서버 설치 없이 바로 사용할 수 있습니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`, `style.css`, `script.js`, `README.md` 파일을 업로드합니다.
3. 저장소의 `Settings`로 이동합니다.
4. 왼쪽 메뉴에서 `Pages`를 클릭합니다.
5. `Build and deployment` 항목에서 다음처럼 설정합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. 저장하면 잠시 후 GitHub Pages 주소가 생성됩니다.

## 사용 팁

- 큰 이미지를 많이 저장하면 브라우저 저장 공간이 부족할 수 있습니다.
- 이미지가 너무 크면 용량을 줄인 뒤 업로드하는 것이 좋습니다.
- 마크다운 기능은 기본적인 문법만 간단히 지원합니다.
